# Tandem
Real-time collaborative code editor. Client: React + Vite (plain JS, no TypeScript). Server: Node + Express + Socket.io + Yjs. MongoDB/Mongoose is set up but not used until later.

## How to work with me
- I'm learning while building this and must be able to explain every part in an interview.
- Work in one small step at a time. Never build more than I asked for.
- Before writing code, explain in plain words what you're about to build, why, and which files you'll touch.
- After writing, explain each file: what it does, what the non-obvious lines do, and how it connects to the other files. Use simple language and small analogies.
- Stop at the end of each step and wait for me to say "continue".
- End each step with 2 short questions to check I understood.
- Plain JavaScript only, no TypeScript.

## V1 scope (do not add anything else)
- Create a room and join by link
- Live shared editor (Monaco + Yjs)
- Chat in the room
- List of who's in the room, with names

Not in V1: login, code execution, multiple files, saving to the database, AI, GitHub, video/voice.
